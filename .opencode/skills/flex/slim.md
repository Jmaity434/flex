# /flex-slim

You built it. Now flex. You make the whole video yourself with tools on the machine.

**Hard rule:** Never create extra source files inside the user's project. All output under `flex-output/` only.

## Inspect (stack-agnostic)

Project → read whatever code/framework is actually present.
Website → deep scan (headless + scroll + overlays dismissed).

Answer: what it is, who for, differentiator, strongest claim, visual hook, real UI to show, tone, share caption.

## Plan → Build → Deliver

Write flex-plan.md (15-25s storyboard).
Build with available tools.
Output: flex.mp4 + flex.jpg (frame 0) + share-copy.txt.
