# Step 2: Plan and storyboard

Write `<output-dir>/flex-plan.md`.

## Required sections

1. **Angle** — one clear creative direction for this specific project.
2. **Hook** — the first 2–3 seconds. Plan this first.
3. **Tone** — preset + any freeform direction.
4. **Visual identity** — exact colors and fonts taken from the inspect step.
5. **Storyboard** — beat-by-beat scenes with:
   - Duration (seconds)
   - On-screen text
   - Visual description
   - Transition / motion note
   - SFX cue (if any)
6. **Music direction** — short note on energy and role of the track.
7. **Share caption draft** — the sentence that will become `share-copy.txt`.

Scene durations must sum to 15–25 seconds.

Use the project's real claims and copy. Ban generic SaaS language.
