# Changelog

All notable changes to flex will be documented here.

## [0.1.0] — 2026-10-02

### Added
- Initial public release of `/flex`
- Stack-agnostic inspect (any language/framework)
- Deep website scan support
- Full + slim modes
- Tone presets with when-to-use guidance
- Voice language auto-detect (`--lang auto`)
- Multi-format output (`--formats`)
- Vertical-first flag
- Multi-platform share copy (X, LinkedIn, Instagram)
- Progress status messages
- `/flex doctor` environment check
- Brand kit support (`--brand`)
- Batch mode (`--batch`)
- A/B tone testing (`--ab`)
- Post-render hooks (`--post-hook`)
- Discovery paths for Claude, Codex, Antigravity, opencode
- Example gallery structure
- Optional assets folder for music/SFX
- GitHub Pages-ready docs site
