/flex

You built it.
Now flex.

An agent skill that turns any project or website into a short, polished launch video — music, motion, and share copy included. Stack-agnostic. One command.

Install

npx skills add https://github.com/Jmaity434/flex --skill flex

Claude Code:

/plugin marketplace add Jmaity434/flex
/plugin install flex@flex

Use

let's /flex
/flex --tone polished --format vertical
/flex --voice
/flex --formats landscape,vertical
/flex --ab default,yc-parody
/flex doctor

Stack-agnostic

Works with HTML, React, Next.js, Vue, Svelte, or whatever the project actually uses. No extra junk files.

Deep website scan

Renders live pages, dismisses overlays, scrolls section by section, extracts real UI and brand.

Multi-format & A/B

Landscape, vertical, square. Compare tones. Multi-platform share copy ready to post.

Every major agent

Claude Code, Codex, Antigravity, opencode, Cursor, and more.
